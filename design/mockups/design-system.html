Design system

The visual system for the app: tokens (colour for dark and light, type, spacing, radii), components and accessibility rules. All values live in tokens.css; nothing else in the mockups defines a colour. Calm, plain and professional: flat surfaces, one accent, no gradients or blur, system fonts.

Type scale

System fonts only: system-ui then common platform fonts, and a monospace stack for addresses, tokens and the log. Two weights: 400 and 600. Line height 1.45. In Slint, set default-font-family to the platform default; sizes map to font-size in logical pixels.

Spacing and radii

A 4 px base. Cards and dialogs use 16 px (cards) or 24 px (dialogs) padding; screens use 24 px gutters; the wizard uses 40 px. Controls are 36 px high (44 px for the primary call to action and the PIN field), with at least a 36 px hit area.

Focus, keyboard and accessibility rules

Applies to every screen. (Slint exposes accessibility through AccessKit on Linux; its quality on each desktop is verified when the UI is built.)

  • Focus ring. 2 px solid --focus, 2 px gap, on every interactive element, never removed. Shown for keyboard use and for programmatic focus (dialogs). Colour is at least 3 : 1 against every surface.
  • Order. Follows reading order: top bar, then navigation, then content, then the footer (Cancel, Back, primary last). Each mockup lists its order under the frame.
  • Dialogs. Focus moves in, is trapped, Escape cancels, focus returns to the opener. The safe action (Cancel, Back to Home) takes initial focus for anything destructive or security-relevant.
  • Everything works without a mouse. Drag and drop of files has a keyboard route (Transfers, Send a file). The desktop toolbar opens with Ctrl+Alt+Shift.
  • Screen readers. Real names for every control (icon buttons carry a label), live regions for progress and errors, no information in colour alone.
  • Motion. Only two animations (a spinner and an indeterminate bar); both stop when the system asks for reduced motion.
  • Text size. Layouts use wrapping and min sizes, not fixed heights; they hold at the system’s larger text settings down to the 900 x 600 minimum.
