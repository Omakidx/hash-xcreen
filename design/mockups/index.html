How to read the pages

Frames

Each framed window is one state of the app, drawn at up to 1280 px wide. One frame is exactly 900 px wide (the minimum window). Resize this browser window to 900 px to see the layouts reflow.

Tags

Phase 2 is in userflow but ships later; the Phase 1 build disables or hides it. Proposed is not in userflow or the protocol and needs the maintainer’s decision.

Not the app

These are static pages: nothing here talks to a server. The remote desktop picture is a placeholder. Everything uses system fonts, so the folder works offline from disk.
