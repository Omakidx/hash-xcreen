Account

This is the Linux account inside your desktop. The password signs you in, locks the screen and authorises sudo. The PIN is what you type to connect.

Lowercase letters, digits, dash and underscore; must start with a letter.
Strength: strong
6 or more digits. Required every time you connect. Five wrong tries remove the device.
Sent once, never stored hereThe password and PIN travel over the encrypted install channel and are kept by the server only as hashes. This app does not save them.
Keyboard order: Username, Password, Confirm password, PIN, Confirm PIN, Back, Next.
Accessibility: strength is text plus a four-segment meter; all four fields are autocomplete="off" and masked.
