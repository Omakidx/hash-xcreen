Keyboard order: skip link to the server list, Add server, App settings, then each card in turn: Connect, Details. Enter or Space activates; arrow keys do not move between cards (Tab only), so that the order stays predictable.
Accessibility: each card is one labelled group; status is a word plus a dot, never colour alone; the thumbnail is decorative (alt empty). Offline Connect is disabled and announced as such.
Slint: a GridLayout of ServerCard components inside a ScrollView; the thumbnail is an Image.

First launch: welcome (empty state)

userflow 1: a short welcome and an Add server button when no server exists. The theme follows the system on first launch; the toggle is in App settings.

Welcome to hash-xcreen

Your own remote desktop, on a server you control. hash-xcreen sets up a desktop on your server, streams it to this app, and keeps it backed up. Nothing runs in anyone else’s cloud.

Set up over SSHGive the app SSH access once; it does the rest.
Or paste one commandRun it on the server yourself, no SSH from here.
Locked by a PINEach device is paired, and the PIN protects the desktop.
Add serverI already installed it: enter a pairing code
Keyboard order: Add server (initial focus), the pairing-code link, App settings.
Accessibility: the heading is the window’s first announced text.

Home at the minimum window size (900 x 600)

The app does not shrink below 900 x 600. At that size the grid drops to two columns of cards; below 640 px of content width it would be one column, which the app does not reach.

Status vocabulary

One badge per state. The card never relies on colour alone.

BadgeMeaningPrimary action
OnlineThe agent answers and the desktop is running.Connect
