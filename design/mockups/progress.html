Need to start over?

Retry is safe at any time. If the server itself is broken you can remove the partial install and begin again.

Keyboard order: focus moves to the Retry button when the failure appears (the banner is announced first). Retry is disabled while it runs; the stage returns to its spinner.
Accessibility: for a failure with retryable: false (for example a verification failure) the primary button becomes Copy log and the text says to contact support; Retry is not offered.
